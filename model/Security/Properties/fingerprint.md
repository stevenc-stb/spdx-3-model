# fingerprint

## Summary

fingerprint as a compact identifier for verifying authenticity and integrity.

## Description

A fingerprint (also called a thumbprint or digest) is a short, unique cryptographic hash value generated from a longer digital object such as a public key, certificate, or file to serve as a compact identifier for verifying authenticity and integrity.
