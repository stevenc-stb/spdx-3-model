# parameter

## Summary

Parameter of a Cryptographic Algorithms.

## Description

Parameter of a Cryptographic Algorithms.

Where the `Key` is the parameter Name from the SPDX cryptographic algorithm list.
Where the `Value` is the parameter value. If More the one value is need use the Cryptography Algorithm parameter Expression string. Ex Key:operationMode Value:[GCM|CCM].
