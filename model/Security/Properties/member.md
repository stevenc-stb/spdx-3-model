# member

## Summary

A Cryptography Algorithm participating in a Algorithm set.

## Description

A member is a Cryptography Algorithm participating in a conjunctive (of type
ConjunctiveCryptographySet) or a disjunctive (of type DisjunctiveCryptographySet)
Algorithm set.

## Metadata

- name: member
- Nature: ObjectProperty
- Range: CryptographyAlgorithm
