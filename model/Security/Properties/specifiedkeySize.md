# specifiedkeySize

## Summary

The default key size or range determined by the authors of the algorithm, standardization or compliance bodies/agencies in bits.

## Description

The default key size, in bits, or a range of key sizes that is specified for a cryptographic algorithm or security mechanism by the algorithm’s authors, standardization bodies, or compliance agencies
If the keySize is not a range set the beginIntegerRange and endIntegerRange to the same value.
