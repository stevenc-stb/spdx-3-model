# KeyTypeEnum

## Summary

KeyTypeEnum the key type .

## Description

A KeyTypeEnum categorizes cryptographic keys. These types help ensure correct handling and security policies within cryptographic systems. Typical key types include public keys, private keys, and symmetric secret keys, each serving specific purposes.

## Metadata

- name: KeyTypeEnum

## Entries

- Public: A public key in a public-private key pair in asymmetric cryptography.
- Private: The private key in a public-private key pair in asymmetric cryptography.
- Secret: A symmetric key used for both encryption and decryption, normally shared between parties.
