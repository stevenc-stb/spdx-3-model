## Summary

A string containing the template format used to structure chat-based interactions with the AI model.

## Description

Specifies the string template used to format conversations for inference or deployment. This template defines the structure for system prompts, user messages, assistant responses, and any special tokens or stop sequences required by the model to correctly parse and generate chat-based interactions.
