# attackFeasibility

## Summary

Specifies the estimated difficulty or effort required to successfully execute an attack against the target asset.

## Description

Associates a threat or risk assessment with a categorized feasibility rating. This property evaluates the technical complexity, required resources, attacker skill level, and time investment necessary to exploit a threat against the target asset. By quantifying execution difficulty, it enables more accurate risk prioritization, mitigation planning, and security posture evaluation.
