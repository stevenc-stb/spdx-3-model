# riskDetectability

## Summary

Specifies the evaluated detectability of a risk event or threat occurrence.

## Description

Associates an assessment with a detectability evaluation instance. This property measures how easily or quickly a risk event, threat, or security incident can be identified by monitoring systems or security operations, influencing the overall risk score and response requirements.

- Nature: ObjectProperty
