# meanTimeToDetect

## Summary

Specifies the average time in seconds required to identify and acknowledge a threat or security event.

## Description

Defines the mean time to detect (MTTD) expressed as a decimal value in seconds. This metric quantifies the performance of detection mechanisms, monitoring systems, and security operations in identifying threats, vulnerabilities, or incidents. When paired with `detectionDifficulty`, it enables precise risk scoring, compliance reporting, and continuous improvement of detection capabilities.
