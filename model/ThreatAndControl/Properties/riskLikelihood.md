# riskLikelihood

## Summary

Specifies the evaluated likelihood of a risk event materializing for the target asset.

## Description

Associates an assessment with a likelihood evaluation instance. This property quantifies the probability or frequency of a threat exploiting a vulnerability and impacting the asset, forming a core component of risk calculation alongside impact and detectability.

## Metadata

- name: riskLikelihood
- Nature: ObjectProperty
- Range: AssessmentLikelihood
