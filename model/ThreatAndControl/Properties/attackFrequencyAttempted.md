# attackFrequencyAttempted

## Summary

Specifies the estimated frequency of attack attempts against the target asset within a defined time period. 

## Description

Associates a threat or control assessment with a `FrequencyMetric` instance to quantify the expected occurrence of attack attempts against the target asset. This property enables the evaluation of attack likelihood by combining a categorical frequency level with a specific time span, supporting risk calculation, prioritization, and resource allocation for mitigation efforts.

- name: attackFrequencyAttempted
- Nature: ObjectProperty
- Range: FrequencyMetric
