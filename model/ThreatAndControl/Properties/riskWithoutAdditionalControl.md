# riskWithoutAdditionalControl

## Summary

Specifies the baseline risk level before implementing additional or compensating controls.

## Description

Defines the risk severity level associated with the threat scenario in its current state, prior to the application of new or enhanced controls. This property serves as a reference point for calculating risk reduction and evaluating the effectiveness of proposed mitigation strategies.
