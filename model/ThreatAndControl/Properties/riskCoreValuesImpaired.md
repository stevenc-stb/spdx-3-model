# riskCoreValuesImpaired

## Summary

Specifies the assessed level of impairment to core security values (e.g., CIA) due to a risk.

## Description

Links an assessment to an impact evaluation focused on the degradation of core security values such as Confidentiality, Integrity, and Availability. This property measures the severity of the adverse effect a risk event would have on the fundamental security attributes of the asset.

- Nature: ObjectProperty
