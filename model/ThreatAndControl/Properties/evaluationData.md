# evaluationData

## Summary

Specifies the underlying data or measurement results used to determine the assessment level or impact severity. 

## Description

Links an impact assessment to the specific `DataAssessment` that provides the empirical evidence, metrics, or measurement results. This property enables traceability between high-level impact categorizations and the underlying quantitative or qualitative data sources that informed the evaluation.

## Metadata

- name: evaluationData
- Nature: ObjectProperty
- Range: DataAssessment
