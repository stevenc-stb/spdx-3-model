# detectionDifficulty

## Summary

Specifies the categorical difficulty level required to identify or detect a threat or security event.

## Description

Associates a detectability assessment with a categorized difficulty rating. This property evaluates how challenging it is for security teams, automated monitoring systems, or operators to identify a threat, vulnerability, or security incident in a given environment. By quantifying detection difficulty, it supports risk prioritization, monitoring strategy refinement, and control effectiveness evaluation.
