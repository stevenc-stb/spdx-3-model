# withThreat

## Summary

Links an assessment with the specific threat being evaluated.

## Description

Associates a security assessment with the specific threat scenario being analyzed. This property defines the potential source of harm or adverse event that the assessment aims to evaluate in relation to the target asset and its associated controls.

## Metadata

- name: withThreat
- Nature: ObjectProperty
- Range: Threat
