# estimatedMeanTimeToContain

## Summary

Specifies the estimated average time in seconds to contain a security incident or threat impact.

## Description

Defines the mean time to contain (MTTC) as a decimal value in seconds. This metric quantifies the efficiency of incident response and remediation processes in limiting the damage or operational impact of a threat. It is used to evaluate the effectiveness of containment controls and recovery procedures.
