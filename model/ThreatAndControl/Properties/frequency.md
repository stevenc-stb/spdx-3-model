# frequency

## Summary

Specifies the categorical level of occurrence frequency for an event or threat.

## Description

Links a instance to its corresponding classification. This property provides the qualitative assessment of how often an event is expected to occur, serving as the primary dimension for frequency-based risk and likelihood evaluations.

## Metadata

- name: frequency
- Nature: ObjectProperty
- Range: FrequencyCategory
