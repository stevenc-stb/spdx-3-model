# ThreatAndControl

## Summary

Enables to model Threats and Controls as different assessment targets.

## Description

The Threats and Controls namespace defines elements and relationships to outline threats, assess threats and controls.

The profile enables to communicate the context and conditions under which the evaluation of Threats are performed. The approach envisions to convey both the resulting protective design and the intended deployment in which Vulnerabilities can be evaluated in context.
