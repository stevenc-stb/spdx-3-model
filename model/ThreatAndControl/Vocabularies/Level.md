# Level

## Summary

Enumeration of impact/contribution severity levels.

## Description

Defines standardized levels used to quantify the contribution, severity, or assurance of security factors.

## Metadata

- name: Level

## Entries

- high: This factor strongly contribute. 
- medium: This factor moderately contribute.
- low: This factor moderately contribute.
- none: This factor does not contribute.
- noAssertion: This factor is not asserted or evaluated.
