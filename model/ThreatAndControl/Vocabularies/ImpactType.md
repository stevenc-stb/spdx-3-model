# ImpactType

## Summary

Enumeration of impact categories for assessments.

## Description

Categorizes the nature of impact evaluated by `AssessmentLevelImpact` classes, distinguishing between threat harm, control protection, and asset requirements.

## Metadata

- name: ImpactType

## Entries

- impacts: The threat causes this type of harm to the system.
- protect: Controls provide this type of protection for the system.
- requires: Assets require this type of safeguard or compliance.
