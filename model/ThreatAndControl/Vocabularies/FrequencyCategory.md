# FrequencyCategory

## Summary

Enumeration of occurrence frequency levels.

## Description

Categorizes how often an event or condition is expected to occur within a defined timeframe. 

## Metadata

- name: FrequencyCategory

## Entries

- rare: Event is very unlikely to occur.
- unlikely: Event is possible but not expected.
- possible: Event may occur under certain conditions.
- likely: Event is expected to occur regularly.
- frequent: Event occurs constantly or continuously.
