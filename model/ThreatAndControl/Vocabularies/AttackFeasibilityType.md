# AttackFeasibilityType

## Summary

Enumeration of how easy or difficult it is to execute an attack.

## Description

Categorizes the technical complexity, required resources, and skill level needed to exploit a threat.

## Metadata

- name: AttackFeasibilityType

## Entries

- veryDifficult: Requires exceptional resources, skills.
- difficult: Requires significant resources, skills.
- moderate: Requires average resources, skills.
- easy: Requires minimal resources, skills.
- trivial: Can be executed with readily available tools and minimal effort.
