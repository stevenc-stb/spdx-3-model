# intendedUse

## Summary

The intendedUse property is designed to capture a summary of how or for what purpose a product is meant to be used.

## Description

The intendedUse field allows users to enter a free-form textual description outlining the scope and boundaries of appropriate or intended applications for the item.

## Metadata

- Nature: DataProperty
- Range: xsd:string
