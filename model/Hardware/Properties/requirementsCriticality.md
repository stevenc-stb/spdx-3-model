# requirementsCriticality

## Summary

Requirements criticality refers to the level of importance a requirement holds in a system, product, or project.

## Description

Requirements criticality refers to the level of importance a requirement holds in a system, product, or project. It helps prioritize tasks, allocate resources, and assess risks associated with missing or failing to implement a requirement. 
1 is the highest level of criticality followed by a descending order of criticality as the number of levels increases.
