# LocationType

## Summary

Indicates whether a relationship is known to be complete, incomplete, or if no assertion is made with respect to relationship completeness.

## Description

RelationshipCompleteness indicates whether the provided relationship is known to be complete, known to be incomplete, or if no assertion is made by the relationship creator.

## Metadata

- name: LocationType

## Entries

- DigitalLocation: A digital location is the location of an object in a digital infrastructure
- MailingLocation: A mailing location is the location that mail is sent.
- PhysicalLocation: Physical location refers to the specific geographical position or site where an object, person, or entity can be found or situated.
